# Введение в бэкенд

Учебный проект по основам бэкенд-разработки. Лабораторные работы последовательно знакомят с HTTP-сервером, CRUD, маршрутизацией и хранением данных в SQLite.

Основной стек - Python и Flask. В первой работе также представлена реализация на TypeScript и Express. Четвёртая работа выполняется отдельным Python-скриптом с модулем `sqlite3`.

## Лабораторные работы

| Работа | Тема | Что реализовано | Отчёт |
| --- | --- | --- | --- |
| [1](lab1/) | Первый HTTP-сервер | GET-маршруты, JSON, параметры пути, информация о сервере, обработка 404. Реализации на Flask и Express | [Открыть](lab1/report.md) |
| [2](lab2/) | HTTP-методы и CRUD | API задач, валидация, поиск, сортировка, пагинация, массовые операции, статистика и журнал запросов | [Открыть](lab2/report.md) |
| [3](lab3/) | Маршрутизация и параметры URL | API товаров, брендов, категорий и отзывов. Вложенные ресурсы, фильтры, статистика и проверка связей | [Открыть](lab3/report.md) |
| [4](lab4/) | SQL и SQLite | Товары и категории, внешние ключи, выборки, JOIN, группировка, подзапросы, транзакции и индекс | [Открыть](lab4/report.md) |

Для работ выполняется вариант 3 повышенного уровня, включая задания предыдущих уровней. Для лабораторной № 2 используется вариант 1.

Отчёты содержат постановку задачи, описание реализации, примеры запросов, результаты и ответы на контрольные вопросы. В папках `media` находятся иллюстрации выполнения.

## Подготовка окружения Python

Для запуска нужен Python 3.11 или новее. Flask используется в работах № 1-3. Работа № 4 использует только стандартную библиотеку Python.

Команды выполняются из корня проекта. Создание и активация виртуального окружения в Linux и macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install Flask
```

В Windows PowerShell окружение создаётся и активируется следующими командами

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install Flask
```

## Запуск лабораторных

Каждая работа запускается отдельно. Все команды приведены для корня проекта с активированным Python-окружением.

| Работа | Команда | Адрес или результат |
| --- | --- | --- |
| 1, Flask | `python lab1/python-flask/server.py` | `http://localhost:3000` |
| 2 | `python lab2/server.py` | `http://localhost:3001` |
| 3 | `python lab3/server.py` | `http://localhost:8080` |
| 4 | `python lab4/db.py` | SQL-запросы и результаты в консоли, файл `lab4/lab4.db` |

### Работа 1. Первый сервер

Сервер предоставляет маршруты `/api/time`, `/api/status`, `/api/info`, `/api/users`, `/api/roles`, `/api/tasks` и `/api/projects`. Пример проверки

```bash
curl http://localhost:3000/api/status
```

Для запуска реализации на Express нужны Node.js и npm. Сначала устанавливаются зависимости и компилируется TypeScript

```bash
npm ci
npm run build:node
npm run start:lab1:node
```

Express использует порт `3000`. Для запуска с автоматическим перезапуском после сборки доступна команда `npm run dev:lab1:node`. После изменения TypeScript-кода необходимо повторить сборку или запустить `npm run build:node -- --watch` в отдельном терминале.

### Работа 2. CRUD задач

Основной ресурс - `/api/tasks`. Поддерживаются получение списка и отдельной задачи, создание, полное и частичное обновление, удаление. Дополнительные маршруты предоставляют массовое создание, статистику и связанные задачи.

```bash
curl http://localhost:3001/api/tasks
curl 'http://localhost:3001/api/tasks?search=задача&sort=id&order=desc'
curl http://localhost:3001/api/tasks/stats
```

Для POST, PUT и PATCH данные передаются в JSON с заголовком `Content-Type: application/json`. Запросы записываются в `lab2/access.log`. Коллекция хранится в памяти процесса и восстанавливается до исходных данных после перезапуска.

### Работа 3. Маршрутизация товаров

Основные ресурсы - `/products`, `/brands` и `/categories/<category>/products`. Поддерживаются поиск, фильтрация, сортировка и пагинация списков товаров. Вложенные маршруты проверяют принадлежность товара бренду или категории и принадлежность отзыва товару.

```bash
curl http://localhost:8080/products
curl 'http://localhost:8080/products?filter=category:food&sort=price&order=desc'
curl http://localhost:8080/brands/1/products/1/reviews/2
curl http://localhost:8080/products/stats
```

Данные хранятся в памяти. Полные описания параметров, статусов и ответов приведены в отчёте работы.

### Работа 4. SQL и SQLite

При первом запуске создаётся файл `lab4/lab4.db`, применяется `init_db.sql` и добавляются исходные товары и категории. Затем выполняются выборки, обновление, удаление и демонстрация отката транзакции.

Изменения сохраняются в файле. Повторный запуск использует текущее состояние базы. Для воспроизведения примеров на исходных данных можно указать новое имя файла

```bash
python lab4/db.py --db lab4/example.db
```

Файлы баз и их служебные файлы в папке `lab4` исключены из Git. Полный вывод демонстрации сохранён в [program-output.txt](lab4/media/program-output.txt).
